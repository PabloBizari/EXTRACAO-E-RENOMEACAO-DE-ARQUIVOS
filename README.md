Automação desenvolvida em PowerShell, com o uso de Inteligência Artificial (IA) como apoio no desenvolvimento e aprimoramento da solução, para localizar, copiar e transferir documentos com base no número de proposta informado pelo usuário.

A ferramenta permite inserir uma ou várias propostas em uma interface simples. A partir dessas informações, ela realiza uma busca automatizada em uma pasta de origem específica — incluindo todas as subpastas — para encontrar arquivos cujo nome comece com o número da proposta digitada.

Quando localizado, o arquivo é copiado automaticamente para uma pasta de destino definida. Caso a proposta possua menos de nove dígitos, a automação também realiza uma segunda tentativa de busca adicionando zeros à esquerda, aumentando a precisão na localização dos documentos. O processo reduz buscas manuais, agiliza a transferência de arquivos e facilita a organização dos documentos por proposta.
